# display/

Screens with a pixel / character / segment model: OLED, TFT, e-paper, character LCD, segment/LED-matrix displays. Addressable LED strips (no framebuffer) go in `led/`. The graphics/font/drawing layer is a sibling library, not part of a panel driver. Contains: SSD1306, ST7735, LED7SEG, CLCD, CLCD_I2C.
