# display/

Screens with a pixel / character / segment model: OLED, TFT, e-paper, character LCD, segment/LED-matrix displays. Addressable LED strips (no framebuffer) go in `led/`. The graphics/font/drawing layer is a sibling library, not part of a panel driver. Contains: ssd1306, st7735, st7789, led7seg, led7_6pin, char_lcd, char_lcd_i2c.
